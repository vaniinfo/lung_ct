# Source matrix for the related-work comparison

Source review date: 2026-11-27. Generated by `scripts/make_comparison_figure.py`; edit the data there, not here.
Statuses: Documented, Partial, Not reported (the examined sources do not describe it; not the same as absent), Unverified; Implemented for ThoraxCheck (validation is described separately in docs/RELATED_WORK.md).

Criteria:

- **C1 Measurements from predicted masks**: At inference the system computes numeric quantities (volume, HU statistics, size or diameter, count, ratio) from segmentation masks it predicts, and uses them in its output. A mask, region crop or heatmap alone does not count.
- **C2 Versioned per-condition rules**: The final answer for each condition is produced by documented, deterministic, condition-specific rules (thresholds, precedence) with a version identifier. A fixed label set, a classifier head, a report template, question answering or a language model deciding does not count.
- **C3 Unresolved state with reason**: The output schema has a state distinct from present / absent (for example 'cannot tell'), emitted under defined conditions, with a reason recorded per item. A free-text verbal refusal or a low confidence score is Partial at most.
- **C4 Image-quality checks in rules**: Measured image-quality properties (noise, inspiration, contrast phase, HU validity, orientation, artefacts) change or block answers. Input format, shape or file validation does not count.
- **C5 Claims linked to evidence**: Each per-condition assessment or report claim references specific evidence items (measurement identifiers, specific tool outputs, masks or regions) that a reviewer can inspect. A reasoning or tool-call trace not tied to individual claims is Partial at most.
- **C6 End-to-end on one 24 GB GPU**: The sources report the complete system (all components needed for its main output) running on one GPU with at most 24 GB, or a whole-pipeline peak memory of at most 24 GB. Parameter count alone does not establish this; a cloud language-model API means the pipeline is not on one local GPU.
- **C7 Structured clinician grading UI**: A user interface in which clinicians view the scan and the outputs and record structured per-item grades that are stored or exported. Having such an interface says nothing about clinical effectiveness.
